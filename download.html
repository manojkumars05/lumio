Download Lumio

📱 Android

Download APK
  1. Download the APK file.
  2. Open it and tap Install.
  3. If blocked, go to Settings and allow installs from this source.
  4. If Play Protect warns you, tap Install anyway.

💻 Windows

  1. Open Lumio in Chrome or Edge.
  2. Click the Install icon (⊕) at the end of the address bar.
  3. Or open the ⋮ menu, then Cast, save and share, then Install Lumio.
  4. Lumio will appear in your Start menu and on your desktop.
