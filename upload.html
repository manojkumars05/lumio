Adding content is limited to admins

Your account can watch videos, but only authorised users can add them. To make yourself an admin (project owner only):

  1. Open the Firebase console → Firestore Database.
  2. Create a collection named admins.
  3. Add a document whose Document ID is your user ID:
  4. Add any field (for example role = admin), save, then reload this page.

Where can I host files for free?

  • Cloudinary (free plan, no card): upload a video or image, then copy its delivery URL (ends in .mp4 / .jpg).
  • Internet Archive (archive.org): upload a file, then use its direct download link.
  • Your own GitHub repo: small clips (under 100 MB) via GitHub Pages, e.g. https://YOUR-NAME.github.io/lumio/media/clip.mp4.

Check each service's current free limits and terms before relying on it. Normal page links (like a YouTube watch page) won't play here; you need a direct file link.
